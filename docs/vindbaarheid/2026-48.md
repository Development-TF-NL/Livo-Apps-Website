## B. Search Console

Niet gemeten. Variabelen `GSC_PROPERTY` (sc-domain:livoapps.software) en `GSC_SERVICE_ACCOUNT_JSON` zijn gezet. De tokenaanvraag bij Google lukt. Alle aanroepen (searchAnalytics en urlInspection) geven HTTP 403 met de boodschap: "Google Search Console API has not been used in project 132315037746 before or it is disabled." De API staat dus niet aan in het Google Cloud-project van het serviceaccount. Er zijn geen cijfers verzonnen. Periode die gemeten had moeten worden: 2026-10-23 tot 2026-11-20.

## Gevonden problemen en herstel

1. `box.png` (1,7 MB, 1254 x 1254 px) werd als gewone `<img>` geladen in de pricing-hero, ook op mobiel waar hij verborgen is. Oorzaak: `PhotoPlace` gebruikte geen `next/image`. Hersteld in `app/components/PhotoPlace.jsx` (import op regel 5, `<Image ... sizes="256px">` rond regel 13). `PhotoPlace` wordt alleen op de pricing-pagina met `src` gebruikt. Build groen met `PRICING_PAGE_ENABLED=true npm run build`. NL en EN delen dezelfde component. Controle na deploy: `curl -s https://www.livoapps.software/nl/pricing | grep -o 'box.png[^"]*'` moet een `_next/image`-URL tonen.
2. Search Console-API staat uit (zie B).
