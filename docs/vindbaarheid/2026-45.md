## B. Search Console

Niet gemeten. `GSC_PROPERTY` (`sc-domain:livoapps.software`) en `GSC_SERVICE_ACCOUNT_JSON` zijn gezet. Tokenaanvraag bij Google lukt (de host is bereikbaar). Daarna geeft elke aanroep (searchAnalytics en urlInspection):

- HTTP 403, "Google Search Console API has not been used in project 132315037746 before or it is disabled."

Oorzaak: de API is niet ingeschakeld in het Cloud-project van het serviceaccount. Het is dus niet de proxy en (nog) niet gebleken of het account gebruiker van de property is. Er zijn geen cijfers verzonnen; de tabellen voor query, pagina, land (NL, BE) en indexdekking ontbreken deze week.
